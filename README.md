# LuxDevHQ Data Analytics Portfolio

Welcome to my learning and project repository for the **LuxDevHQ Data Science & Analytics Programme**. It brings together my coursework, data analysis projects, dashboards, technical notes, and learning resources across Excel, SQL, Power BI, Python, and statistics.

I am a Civil and Structural Engineering graduate transitioning into data analytics. My engineering experience has given me a practical foundation in problem-solving, precision, and working with real-world data.

## Projects and Coursework

### Excel

- **[Jumia Product Analysis](Excel/Jumia_Product_Analysis/README.md)** — end-to-end analysis of 165 Jumia Kenya product listings. Cleaned and enriched the data, explored pricing, discounts, ratings, and reviews, and built an interactive dashboard. The project includes the workbook and a data-cleaning document.
- **[Sales and Operations Analytics](Excel/Sales%20and%20Operation%20Analytics/README.md)** — cleaned and analyzed 632 sales transactions, created business and operational metrics, performed scenario analysis, and built an executive dashboard.
- **[Excel in Real-World Data Analysis](Excel/Articles/How_Excel_Is_Used_In_Real_World_Data_Analysis.md)** — an article on Excel use in financial reporting, HR, and project tracking.

### SQL and PostgreSQL

- **[SQL learning notes](SQL/)** — a six-part reference covering database fundamentals, filtering and sorting, aggregation, joins/subqueries/CTEs, window functions, and data cleaning/functions. Includes a PostgreSQL functions reference.
- **[Sunrise Supermarket](SQL/sql_week1_assignment_benjamin/sunrise_Supermarket_Project/Sunrise_Supermarket_README.md)** — database design and querying practice using related customer, order, product, and order-item tables.
- **[Afya Bora Clinic](SQL/sql_week1_assignment_benjamin/clinic_assignment/README.md)** — `CASE WHEN`, conditional aggregation, and joins practice.
- **[Greenwood Academy](SQL/sql_week2_assignment_benjamin/README.md)** — a PostgreSQL database assignment covering schema/table creation, data changes, queries, operators, counts, and conditional logic.

### Power BI

- **[Kenya Crops Monitor](PowerBI/Kenya_Crops_Dataset/PowerBI.md)** — agricultural analysis using Power Query transformations, calculated fields, DAX measures, and interactive county, crop, seasonal, and operational views.
- **JCARS and Students** — Power BI files and supporting dataset/cleaning documents are in [Public_Jcars](PowerBI/Public_Jcars/) and [Students_Dataset](PowerBI/Students_Dataset/).
- **Safari Connect** — a Power BI project file is in [SQL/Project/Safari_connect](SQL/Project/Safari_connect/).
- **[Before Power BI Can Work Its Magic, Your Data Needs a Blueprint](PowerBI/PowerBI_Article.md)** — an article about schemas, joins, data modeling, and schema designs. [Read the published article on DEV.to](https://dev.to/benjamin_ogol_1af8e695c87/the-invisible-architecture-behind-every-great-power-bi-report-3cam).

### Python and Statistics

- **[Statistics and data science notebook](Stats_DS/code/stats_ds.ipynb)** — Jupyter notebook work alongside the [Nairobi rentals dataset](Stats_DS/data/nairobi_rentals_reemio.csv).
